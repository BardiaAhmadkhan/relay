## Contingencies
No API: local actual recognition, physical review. No network to laptop: demonstrate native capture and disclose that analysis is unavailable; use a separately labeled recorded demo if permitted. No supported phone: do not call the browser a mobile-device demonstration. No time: preserve core safety/recovery and remove optional polish. Unexpected data: sample openly, record unsupported inputs, adapt one decoder or request a supported capture.
