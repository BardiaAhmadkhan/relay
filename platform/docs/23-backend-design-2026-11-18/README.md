**Size ceiling.** The verified model and vision projector total **3,324,162,336 learned bytes**. The complete registry-reported package is **3,324,173,934 bytes**. Candidate hosting designs must fit within both limits. The conservative design also caps the total parameter count at 4,539,265,536. The mobile model budget is zero.

**Scope.** Code and model artifacts in the Relay working tree were inspected and tested as they stood. This handoff contains design, research and verification evidence. Cloud hosting, physical-device validation, protective-area repair performance and prospective field accuracy remain open.

The ZIP contains all seven handoff files, with no photos, weights or application source. Relative links to older evidence under `../../benchmarks`, `../../packages`, `../../scripts` or adjacent historical `docs` chapters resolve in the original Relay checkout. The new report and ledger carry the relevant measurements for someone reading the ZIP on its own.
